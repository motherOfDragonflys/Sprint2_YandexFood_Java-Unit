# ShoppingCart Demo — расчёт стоимости корзины с учётом скидок

Демонстрационный проект на Java: расчёт итоговой стоимости товаров в корзине, применение скидок для отдельных категорий и подсчёт стоимости вегетарианских продуктов.

### Требования
- JDK 11 или выше
- Maven 3.5.0 или выше

### Запуск

```bash
mvn clean compile exec:java
